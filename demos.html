What this is

MooTools was a JavaScript framework that competed with jQuery in the late 2000s. These plugins were written against it around 2011 and published to the MooTools Forge. The framework is long retired and none of this reflects how I write JavaScript now.

They stay here for one reason: the URLs have been linked from elsewhere for over a decade, and breaking them to tidy up a portfolio is a bad trade.

MooTools plugins

  • RectangleSelection — drag a marquee to select multiple elements
  • Drag.Move.Collide — dragging with collision detection
  • Drag.Move.Inside — constrain dragging to a container
  • Element.Collide — test whether two elements overlap
  • Element.serializeArea — serialise an image map area
  • Element.Inside — test whether one element contains another
  • EncodeAndDecodeXML — XML entity encoding helpers
  • GUID — client-side GUID generation
  • listManager — add, remove and reorder list items
  • minimizeCode — collapse source for display
  • mooStripe — Stripe payment integration
  • ScrollBarCover — custom scrollbar overlay
  • urlFriendly — slugify strings for URLs
