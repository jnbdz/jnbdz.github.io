Draft spec Author

View Descriptor Protocol

A protocol that lets an API declare which templates render its responses, so the mapping lives in one place instead of being hardcoded into every client. Descriptors nest recursively, travel inline or in a Link header, and sit alongside REST, HAL and OData rather than replacing them.

JSON · HAL · RFC 8288 · OData

An electronic flight bag for VFR pilots.
